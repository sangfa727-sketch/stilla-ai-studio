# STILLA Desktop UX Prototype

Open `index.html` directly in a modern browser. It uses only HTML, CSS, and vanilla JavaScript; no package install, server, or network access is required.

## Included interactions

- Seven separate navigation destinations: Projects, Script & Storyboard, Generate, Edit Studio, Assets & History, Export, Settings.
- Responsive desktop-first shell and compact/mobile navigation behavior.
- Dark/light theme toggle.
- Persistent sample task-queue panel across navigation.
- Demonstration interactions for script draft text, scene addition, asset search/filter, timeline zoom, settings fields, and export preflight messaging.

## Important limitations

This is a visual/interaction prototype, not the production application. Project counts and assets are sample data. It does not persist project data, connect to Bionic/Qwen, make network requests, import media, edit real video, launch image/video generation, or render exports. Controls that would require those systems explicitly say they are not connected or show an illustrative response.

Do not use this prototype to infer model readiness, production security, actual export capability, or performance. The next implementation stages must connect real services behind validated application-core contracts and add automated browser tests before calling any workflow functional.
